# AT THE CODE Home — Landed Cost Working

Internal owner file. Use this before approving imported products.

## Core rule
Do not approve an Alibaba product from the visible product price alone. We need an all-in UK landed figure and the compliance documents for the exact model.

## What counts as landed cost
- Supplier product price
- International freight
- Insurance/packing if charged
- Customs duty where applicable
- Import VAT unless the supplier quote is DDP and genuinely includes it
- Courier/port/clearance/handling charges
- Final UK delivery to the customer
- Allowance for damage/returns/replacements

For imports over £135, UK import VAT is normally due. HMRC values import VAT using customs value plus duty and incidental costs such as transport and insurance. For launch, prefer written DDP all-in quotes to the customer postcode so there are no surprise charges.

## UK retail benchmark notes
These are retail price anchors only, not approved stock or suggested suppliers:
- UK boneless/boxed two-seater examples can retail around £246+.
- Larger modular/U-shaped sofa examples can retail around £700+.
- Birlea wardrobes commonly retail around £195–£320+ depending on range/model.

Use these only to judge whether imported landed cost leaves enough room for customer service, returns, payment fees and profit.

## Margin gate
Before listing an imported sofa, target a landed cost no higher than roughly 60–65% of the intended selling price. The remaining 35–40% is not all profit: it must absorb payment fees, customer-service time, refunds/damage, marketing, and actual profit.

Example rule:
- If retail target is £449, maximum preferred landed cost is about £270–£292.
- If retail target is £599, maximum preferred landed cost is about £359–£389.
- If retail target is £699, maximum preferred landed cost is about £419–£454.

A supplier quote above those ceilings should usually be rejected unless the product is unusually strong and return risk is very low.

## UK compliance gate for imported upholstered furniture
Domestic upholstered furniture supplied in the UK remains subject to the Furniture and Furnishings (Fire) (Safety) Regulations as amended in 2025. The 2025 changes removed the display-label requirement but did not remove permanent-label requirements for in-scope products. Never accept a generic "CE" badge as proof that a sofa is lawful for UK retail.

## Next quote request fields
Every shortlisted Alibaba supplier must answer all of these in one written quote:
- Product/model code
- Quantity: 1 unit
- DDP price to UK residential postcode
- All taxes/duty/clearance included? yes/no
- Who is importer of record?
- Delivery lead time
- Final-mile delivery type (kerbside / doorstep / room of choice)
- Neutral packaging available?
- UK fire-compliance reports for exact model
- Permanent UK furniture label supplied?
- Warranty
- Damage/DOA claim deadline
- Replacement/refund process
- Return address and who pays freight
- Photo/video resale rights
- Stock availability and whether one-unit orders can be repeated without MOQ increase
